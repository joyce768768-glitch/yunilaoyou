# 与你老友 · AI 人物群聊决策答疑

移动端 AI 群聊产品：用户向多个 AI 人物角色提问，**多 Agent 各自推理后协同输出决策建议**——探索「群聊」这一天然多 Agent 交互范式。

## 交互范式

```text
用户提问 → 群内多个 AI 角色各自推理
        → 角色间观点互补 / 碰撞
        → 协同产出结构化决策建议
```

- **多 Agent 协同**：每个 AI 角色独立人格与推理视角，避免单模型单一答案的扁平感
- **群聊即编排**：借用户熟悉的群聊心智承载多 Agent 协作，零学习成本
- **双端交付**：产品官网 + 移动端应用

## 技术栈

`Web（HTML/JS 官网 + H5 应用）`
